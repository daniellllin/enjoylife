# 一起走走 · enjoy life

把散落在社群、地圖與訊息裡的收藏，整理成兩個人真的會一起去的清單。

- 作品介紹：<https://daniellllin.github.io/enjoylife/showcase/>
- 示範版：<https://daniellllin.github.io/enjoylife/demo/>

## 公開版本的邊界

這個資料夾只包含作品介紹與公開示範版。示範版：

- 全部使用虛構地點與圖片。
- 不登入、不讀寫正式 Beta，也不連 Supabase。
- 不呼叫 Google Maps、社群網站或其他外部 API。
- 資料只存在目前頁面的記憶體，重新整理即還原。

正式 Beta 的原始碼、帳號設定、雲端資料與私人收藏不在此發布包中。

## 技術

HTML、CSS、原生 JavaScript；正式 Beta 使用 React 19、Vite、Supabase、Cloudflare Workers、Leaflet 與 Playwright。
